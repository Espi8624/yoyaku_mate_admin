# 実装詳細書：データベースメトリクスダッシュボード (DB Metrics Dashboard)

本書は `yoyaku_mate_admin` (React フロントエンド) に実装された MongoDB データベースのリアルタイムパフォーマンスダッシュボードの技術的設計および UI/UX 実装事項を説明します。

> 作成日: 2026-07-26  

---

## 1. フロントエンド実装詳細 (`yoyaku_mate_admin`)

### 2.1 画面構成 (`src/pages/DbMetricsPage.jsx`)
管理者がシステムの健康状態を一目で把握できるよう、3つの主要指標カードで構成されています。

1. **ACTIVE CONNECTIONS (アクティブなコネクション)**
   - カラー: `COLORS.success` (緑色)
   - 説明: バックエンドサーバーが DB と事前に結んで維持しているコネクションプール (Connection Pool) の数です。
2. **DATABASE SIZE (データベース容量)**
   - カラー: `COLORS.info` (青色)
   - 説明: 現在のデータベースがディスク上で占有している物理容量です。（単位：MB）
3. **SLOW QUERIES (24H) (スロークエリ)**
   - カラー: `COLORS.error` (赤色)
   - 説明: 過去24時間で処理時間が200msを超過した通信の件数です。システムのボトルネックを把握する中核アラート (Warning) として機能します。

### 2.2 ユーザーエクスペリエンス (UX) の改善事項
- **直感的な単位表記**: 当初の GB 単位からサービス規模に合わせて **MB（メガバイト）** 単位に調整し、小数の表示を最小限に抑えて直感性を高めました。
- **ナビゲーションの連動**: SLOW QUERIES カードの下部に **[詳細を見る]** ボタンを追加し、問題発生時にすぐに `ResponseTimePage` (遅いエンドポイント Top 10) 画面に移動して原因を把握できるよう動線を設計しました。(`react-router-dom` の `useNavigate` を活用)
- **エラーハンドリング**: バックエンドの通信失敗時に画面が崩れることなく、上部に赤い `<Alert />` コンポーネントでエラー状況 ("データベース指標の読み込みに失敗しました。") を案内するように設計されています。
