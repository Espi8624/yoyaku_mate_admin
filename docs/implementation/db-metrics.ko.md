# 구현 상세서: 데이터베이스 메트릭스 대시보드 (DB Metrics Dashboard)

본 문서는 `yoyaku_mate_admin` (React 프론트엔드)에 구현된 MongoDB 데이터베이스 실시간 성능 대시보드의 기술적 설계 및 UI/UX 구현사항을 설명합니다.

> 작성일: 2026-07-26  

---

## 1. 프론트엔드 구현 상세 (`yoyaku_mate_admin`)

### 2.1 화면 구성 (`src/pages/DbMetricsPage.jsx`)
관리자가 시스템의 건강 상태를 한눈에 파악할 수 있도록 3개의 핵심 지표 카드로 구성되었습니다.

1. **ACTIVE CONNECTIONS (활성화 커넥션)**
   - 컬러: `COLORS.success` (초록색)
   - 설명: 백엔드 서버가 DB와 미리 맺어두고 유지 중인 커넥션 풀(Connection Pool)의 개수입니다.
2. **DATABASE SIZE (데이터베이스 용량)**
   - 컬러: `COLORS.info` (파란색)
   - 설명: 현재 데이터베이스가 디스크에서 차지하고 있는 물리적 용량입니다. (단위: MB)
3. **SLOW QUERIES (24H) (느린 쿼리)**
   - 컬러: `COLORS.error` (빨간색)
   - 설명: 최근 24시간 동안 처리 시간이 200ms를 초과한 통신 내역의 건수입니다. 시스템 병목 현상을 파악하는 핵심 알람(Warning) 역할을 합니다.

### 2.2 사용자 경험 (UX) 개선 사항
- **직관적인 단위 표기**: 초기 GB 단위에서 서비스 규모에 맞게 **MB(메가바이트)** 단위로 조정하여 소수점 노출을 최소화하고 직관성을 높였습니다.
- **네비게이션 연동**: SLOW QUERIES 카드 하단에 **[詳細を見る (상세 보기)]** 버튼을 추가하여, 문제 발생 시 즉시 `ResponseTimePage` (느린 엔드포인트 Top 10) 화면으로 이동해 원인을 파악할 수 있도록 동선을 설계했습니다. (`react-router-dom`의 `useNavigate` 활용)
- **에러 핸들링**: 백엔드 통신 실패 시 화면이 깨지지 않고 상단에 붉은색 `<Alert />` 컴포넌트로 에러 상황("データベース指標の読み込みに失敗しました。")을 안내하도록 설계되었습니다.
